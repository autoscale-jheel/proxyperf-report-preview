What the numbers say

Data center was the stronger product on this site. All 8 data center providers opened the page on every try. The fastest residential latency, 596 ms, was still slower than four data center providers.

SquidProxies data center led on both latency and speed. The next latency was IPRoyal at 350 ms. The next speed was Bright Data data center at 76 Mb/s.

A page that opens can still be slow. Proxy-Cheap opened 4 of 5 tries, and the total time on those tries averaged 10.7 seconds. Geonode opened all 5, with latency of 2,184 ms and a total time of 5.8 seconds.

For BBC News, use SquidProxies data center. If you need a residential address, use SquidProxies residential.

SquidProxies residential is the name on ProxyPerf. The test file calls this pool DynaProx. Latency figures are rounded to the nearest millisecond. Speed figures are rounded to the nearest Mb/s, except 0.7.

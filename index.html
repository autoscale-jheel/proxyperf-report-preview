🔍 What Each Benchmark Metric Measures
How ProxyPerf tests, verifies, and calculates performance indicators for custom destination URLs.
✓
Validated HTTP Delivery
Every request confirms that the target server returned a genuine HTTP 200–399 response, verifying there were no proxy dropped connections or 5xx gateway errors.
✓
Success Rate (Reliability)
The percentage of test attempts (out of 5 probes) that successfully reached and loaded the target without network timeouts or connection interruptions.
✓
Latency to First Byte (TTFB)
Measures the exact response time (in milliseconds) until the first byte of page content is received from the destination server through the proxy.
✓
Connect Overhead
Measures the handshake time taken to establish the proxy tunnel connection before making the outbound request to the destination website.
✓
Speed: How Fast Data Downloads
Average network download speed (in Mb/s) measured by transferring a standardized 10 MB payload directly through each active proxy tunnel.
✓
Multi-Cycle Probing
Tests run across 5 sequential attempts with a 10s connect timeout and 30s total timeout to prevent one-off flukes from skewing provider averages.
Benchmark Methodology: Each provider was measured using 5 independent HTTP GET probes against the target URL through dedicated proxy tunnels. Latency measures Time to First Byte (TTFB). Speed throughput measures bandwidth over an isolated 10 MB payload test. Conducted via ProxyPerf automated test runner.
